# `@hiraya-team/apps-ui`

Solid controls for Hiraya applications. Applications bundle this package and provide the semantic `--hiraya-*` theme variables supplied by the Hiraya SDK.

```tsx
import { Button } from "@hiraya-team/apps-ui";
import "@hiraya-team/apps-ui/styles.css";

<Button>Save</Button>
```

`Button` accepts native button properties and defaults to `type="button"`.
